# 💡 Overview

This project provides a simulated trading environment allowing users to manage a virtual cash reserve, buy and sell market equities, monitor portfolio allocations in real time, and export financial statements to persistent text storage.

# ✨ Key Features

- 💵 **Integrated Cash Wallet:** Starts with a virtual cash balance ($10,000.00 default) that dynamically updates with market transactions.
- 🛒 **Buy & Sell Mechanics:**
  - **Capital Checks:** Prevents orders when cash reserves are insufficient.
  - **Holdings Validation:** Prevents short-selling or selling more shares than currently owned.
  - **Automatic Position Pruning:** Automatically cleans up closed positions once holdings hit zero.
- 📊 **Comprehensive Net Worth Dashboard:** Displays individual stock quantities, real-time values, available liquid cash, and aggregate net account worth.
- 🛡️ **Robust Input Sanitization:** Gracefully intercepts alphabetic mismatches, negative quantities, and unlisted ticker requests without crashing.
- 📁 **File Export Capability:** Generates a formatted text summary statement (`portfolio_statement.txt`) with a single click.
